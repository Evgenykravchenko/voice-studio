# Voice Studio · сервер

[English](README.md) · **Русский** · [Документация пользователя](../README.ru.md)

Java 21 и Spring Boot. В обычном режиме API и готовый интерфейс работают на
`127.0.0.1:4173`; при разработке API — на 7080 за Vite. Полное приложение
запускается корневым скриптом. [Разработка и проверки →](../docs/development.ru.md)

## Задачи сервера

Сервер проверяет запросы, последовательно выполняет задания моделей, управляет
загрузками и сохраняет проекты с метаданными. SQLite встроена. Python запускается
по необходимости, дополнительные окружения работают в отдельных дочерних процессах.
API доступен через loopback и предназначен для одного локального пользователя.

## Карта API

| Путь | Назначение |
| --- | --- |
| `/api/health` | Возможности API, наличие worker и идентификатор проекта. Готовность API не означает загрузку модели в память. |
| `/api/models` | Каталог, готовность и выбор; дополнительные маршруты скачивают, отменяют и выбирают модель. |
| `/api/projects` | Создание и список; маршруты по ID загружают и сохраняют с проверкой ревизии. |
| `/api/voices`, `/api/voice-imports` | Профили и асинхронная подготовка/проверка/сохранение образца. |
| `/api/jobs`, `/api/recordings` | Озвучка, состояние заданий и страницы истории записей. |
| `/api/audio/{id}` | Готовое аудио с поддержкой перемотки. |
| `/api/projects/{id}/assembly` | Сборка микса сохранённого проекта. |
| `/api/cleanups` | Загрузка, улучшение, сравнение, настройка и применение результатов. |
| `/api/media` | Загрузка исходников для инструментов моделей. |

Точные методы и схемы запросов определены в API-классах
[`src/main/java/local/voicestudio`](src/main/java/local/voicestudio).
Задание хранит исходные настройки. После перезапуска прерванное задание получает
ошибку, готовые результаты сохраняются. Не собирайте JAR поверх работающего.

## Данные

База — `data/studio/studio.db`, метаданные — `data/studio/`, профили —
`data/profiles/`, аудио — `outputs/`. Следуйте [руководству резервного копирования](../docs/storage.ru.md),
а не копируйте один SQLite-файл во время записи. Журналы Python и загрузок —
в `.runtime/logs/`.
