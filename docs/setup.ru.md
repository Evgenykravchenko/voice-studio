# Установка

[English](setup.md) · **Русский** · [На главную](../README.ru.md)

## Перед началом

| Требование | Что нужно |
| --- | --- |
| Компьютер | Mac на Apple Silicon: M1 или новее. Intel Mac не поддерживается. |
| Система | macOS 14 или новее. Windows и Linux запланированы. |
| Интернет | Для первой установки, скачивания моделей и обновлений. |
| Диск | Место для приложения, инструментов, выбранных моделей и кэшей загрузки. |
| Память | Зависит от модели; см. [заметки о памяти](models.ru.md#память-и-диск). |

Запуск устанавливает собственные Java, Python, Node.js, pnpm, Maven и uv внутри
проекта. FFmpeg входит в зависимости Python. Homebrew и глобальные пакеты не
требуются. Храните проект в обычном каталоге с правом записи.

## Установка и запуск

1. Скачайте **Code → Download ZIP** и распакуйте архив либо используйте Git-клиент.
2. Откройте распакованную папку проекта в Терминале.
3. Выполните:

```sh
./scripts/studio.sh
```

В новой копии подготовка выполнится автоматически. Дождитесь завершения и
откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).
При ошибке сохраните её полный текст.

Первый запуск устанавливает приложение, **а не все модели**. Откройте «Модели»:

- **Fish S2 Pro + Whisper Small** — клонирование голоса и озвучка текста.
- **Один из голосов Piper** — готовый русский голос без собственной записи.
- **Resemble Enhance** — улучшение аудио без профиля клонирования.

Модель доступна после проверки файлов и подготовки зависимостей. Некоторые
загрузки большие — дайте установке время на медленном соединении.
[Выбрать модель →](models.ru.md)

## Повторный запуск и остановка

Используйте тот же скрипт: он повторно использует инструменты и данные.
Оставляйте его окно Терминала открытым. Для остановки нажмите в нём **Ctrl+C**.
Закрытие вкладки браузера само по себе сервер не останавливает.

Работающая студия этого проекта используется повторно. Если порт 4173 занят
другим приложением, запуск сообщит о конфликте. Остановка прерывает незавершённые
задания; сохранённые проекты и готовые результаты остаются.

Fish освобождает модель через 180 секунд простоя. Остальные модели выполняют
задания в отдельных процессах, которые завершаются после обработки. У работающего
сервера может оставаться небольшой ожидающий процесс Python.
Постоянного прослушивания микрофона нет.
