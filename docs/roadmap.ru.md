# Планы развития

[English](roadmap.md) · **Русский** · [На главную](../README.ru.md)

Voice Studio 0.1.1 работает локально на macOS 14+ с Apple Silicon.
Здесь указаны направления работы без обещания сроков. Что поддерживается уже
сейчас, описано в [состоянии выпуска](status.ru.md).

## Уже доступно

- Озвучка с профилями голосов, готовыми дикторами и описанием голоса в подходящих моделях.
- Каталог 45 скачиваемых моделей для синтеза, распознавания и обработки аудио.
- Сохранение проектов и дублей, монтаж сцен и экспорт итоговой записи.
- Улучшение аудио с раздельным удалением шума и восстановлением, сравнением до и после.
- Русский и английский интерфейс, светлая, тёмная и системная темы.

## Дальнейшие направления

| Направление | Желаемый результат |
| --- | --- |
| Обратная связь о первом запуске | Понятнее объяснять ошибки установки и выбор моделей на разных Mac с Apple Silicon. |
| Место под модели | Удалять установленную модель из интерфейса и видеть занятое ею место. |
| Windows и Linux | Подключить окружения под каждую систему, проверить установку и реальную обработку. Пока эти ОС не поддерживаются. |
| Рекомендации по речи | Дополнить примеры для произношения, длинных текстов и выразительной подачи с учётом модели. |
