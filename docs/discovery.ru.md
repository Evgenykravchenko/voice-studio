# Сайт проекта и поиск

[English](discovery.md) · **Русский** · [Документация](README.ru.md)

[Публичный сайт проекта](https://evgenykravchenko.github.io/voice-studio/ru/)
рассказывает о студии и показывает модели на русском и английском. GitHub Pages
размещает статические страницы, а само приложение пользователь устанавливает локально.
Сейчас Pages включён в GitHub Free для публичных репозиториев с учётом
[ограничений GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).
Для этого сайта не нужны платный сервер, отдельный домен и постоянно включённый Mac.

## Что настроено

- Описание репозитория, подходящие теги и ссылка на сайт для поиска GitHub.
- README с задачами приложения и названиями семейств моделей.
- Четыре статические страницы: главная и каталог на русском и английском.
- Отдельные заголовки и описания, канонические адреса каждой страницы, взаимные языковые ссылки `hreflang`.
- XML-карта страниц, метаданные для ссылок в соцсетях, локальные скриншоты и иконка.
- JSON-LD `WebPage` и `SoftwareSourceCode` с описанием проекта и репозитория. Это не обещание расширенного результата или звёздного рейтинга в Google.

Сайт работает без JavaScript, не скачивает модели, не подключает аналитику
и рекламные скрипты. В публикацию попадают только проверенные HTML, CSS,
иконка, два обезличенных скриншота и карта страниц.

## Как обновлять

Тексты обоих языков находятся в `site/content.json`. Каталог берётся напрямую
из `src/voice_cloner/model-catalog.json`; отдельный список моделей вести не нужно.
Для сборки достаточно стандартной библиотеки Python:

```sh
./.venv/bin/python scripts/build-site.py
./.venv/bin/python scripts/check-site.py
```

Результат находится в исключённой из Git папке `.runtime/site/`. Проверка отклоняет
лишние файлы, сломанные внутренние ссылки, пропущенные метаданные, несогласованные
языковые ссылки и расхождения с каталогом. Workflow Pages выполняет те же проверки
перед публикацией изменений сайта, каталога и скриншотов из `main`.

## Необязательное подключение Google Search Console

1. В [Search Console](https://search.google.com/search-console/welcome) добавьте **ресурс с префиксом URL**: `https://evgenykravchenko.github.io/voice-studio/`.
2. Выберите подтверждение **HTML-тегом**. Запишите значение `content` из тега в `googleSiteVerification` файла `site/site.json` и опубликуйте сайт. Это публичный код подтверждения, не пароль Google и не API-ключ.
3. После появления тега на главной странице нажмите **«Подтвердить»** в Search Console. Сохраняйте тег при дальнейших обновлениях.
4. В **Sitemaps** отправьте `https://evgenykravchenko.github.io/voice-studio/sitemap.xml`. Через проверку URL можно запросить индексацию главной страницы и каталога.

Подтверждение и отправка карты требуют Google-аккаунта владельца. Публикация
сайта не выполняет эти шаги автоматически. Google может найти страницы
и без Search Console. Шаги описаны в [инструкции Google](https://support.google.com/webmasters/answer/9008080?hl=ru).

Файл `robots.txt` в папке проекта не создаётся: поисковик читает его в корне
домена, выше `/voice-studio/`. Сайт отдаёт доступный для индексации HTML и ссылку
на карту страниц. Не обозначайте файл из подпапки как управляющий Googlebot.

## Как оценивать результат

В [поиске репозиториев GitHub](https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories)
по умолчанию участвуют название, описание и теги. Для README есть `in:readme`.
После индексации можно проверить `user:Evgenykravchenko topic:voice-cloning`
и `user:Evgenykravchenko Qwen3-TTS in:readme`.

Показы, клики, запросы и состояние индексации Google смотрите в Search Console.
Запрос `site:` даёт лишь приблизительную проверку, а не полный отчёт об индексе.
Карта помогает обнаружить страницы, но не гарантирует индексацию, позиции,
посещения или звёзды. Это объясняет [документация Google](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl).
Полезные выпуски, примеры звучания и настоящая обратная связь помогают людям
оценить проект. Публикуйте анонсы только с разрешения владельца.
