# Данные и обновления

[English](storage.md) · **Русский** · [На главную](../README.ru.md)

## Что сохраняется

Проекты сохраняются автоматически. Перед закрытием дождитесь **«Сохранено на
сервере»**. Новый браузер может загрузить проекты с локального сервера; хранилище
браузера служит дополнительным черновиком и хранит язык с темой.

| Где | Что хранится |
| --- | --- |
| `data/` | База проектов, образцы голосов, настройки заданий, загруженные исходники и история обработки. |
| `outputs/` | Озвучка, собранные миксы и обработанные записи. |
| `.runtime/` | Локальные инструменты, веса моделей, дополнительные окружения, кэши и журналы. |
| `.venv/` | Основное окружение Python. |

Эти папки исключены из Git. Старые локальные примеры, если они есть, также
приватны: `frontend/public/audio/` и их манифест `frontend/src/audio-data.json`.

JSON-экспорт проекта содержит текст, настройки и идентификаторы записей.
**В нём нет самих WAV и образцов голоса.** Для полного восстановления нужны данные на диске.

## Резервная копия

1. Дождитесь сохранения, остановите задания, затем завершите студию через Ctrl+C.
2. Скопируйте **папки `data/` и `outputs/` целиком** в отдельное место.
3. Если используются старые локальные примеры, сохраните также их папку и манифест.

Можно копировать всю остановленную папку проекта, но туда попадут и большие кэши.
Веса скачиваются заново; личные записи из JSON проекта не восстанавливаются.
Не копируйте только основной SQLite-файл во время работы приложения: актуальные
изменения могут находиться в WAL-файлах рядом с ним.

## Обновление

Сначала остановите студию и сделайте копию данных. Обновите исходники через
Git-клиент, затем один раз выполните из папки проекта:

```sh
./scripts/bootstrap.sh
```

Дальше запускайте обычным скриптом. Bootstrap обновляет зависимости и сборку,
не удаляя ваши данные. Работающую студию он обновлять откажется.

Если проект скачан ZIP-архивом, распакуйте новую версию в отдельную папку,
скопируйте в неё сохранённые data и outputs, затем запустите приложение.
Установите нужные модели в новой копии. Старую папку оставьте до проверки переноса.

## Перенос и удаление

Для переноса существующей установки на совместимом Mac остановите приложение
и переместите папку целиком. При запуске проверяются пути Python; при необходимости
установка восстанавливает их. Перенос на другую ОС пока не поддерживается.

Для удаления остановите приложение, вынесите резервные копии за пределы папки
и удалите сам проект. Глобально установленный Python или Java удалять не потребуется.

В каталоге пока нет кнопки удаления отдельной модели. Не удаляйте общие
Hugging Face blob-файлы вручную. При намеренной очистке **всего** кэша моделей
на остановленной студии веса придётся установить заново; `data/` и `outputs/`
нужно сохранить. Экономнее сразу скачивать только нужные модели.
