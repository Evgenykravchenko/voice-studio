# Голоса, модели и разметка

Здесь описаны подключённые элементы Voice Studio, а не все возможности исходных
моделей. Состояние проверки описано в [отчёте выпуска](release-status.md), измерения
собраны в [таблице памяти](model-resources.md). Успешное создание файла не гарантирует
правильность каждого слова, ударения или сходство любого голоса.

## Обычный маршрут

1. В «Моделях» установите нужную модель. Дождитесь готовности: приложение также
   устанавливает её библиотеки, словари и кодеки. Затем выберите модель в озвучке.
2. Для клонирования создайте профиль в «Голосах»: запись одного человека,
   фрагмент 5-30 секунд, точная расшифровка. Перед сохранением проверьте её.
   F5 принимает английский/китайский эталон; для VibeVoice Large короткие эталоны
   особенно требуют проверки результата.
3. Для готового голоса выберите вариант из списка. Для создания по описанию
   заполните описание или доступные параметры голоса. Профиль для этих режимов
   не требуется. Выбор режима зависит от модели.
4. Напишите текст сцены, выберите доступную подачу и создайте дубль. Настройки
   дубля фиксируются при отправке. Правки текста и подачи меняют следующие дубли.
5. В «Монтаже» выберите дубли, обрежьте края, расставьте сцены и паузы,
   отрегулируйте громкость и соберите итог. Оригиналы остаются доступны.

Язык интерфейса не переводит текст и не меняет язык озвучки. Когда показано
«Автоматически», язык определяется по тексту самим подключённым адаптером.
Выбор русского интерфейса не добавляет русский язык английской модели.

Общая пауза `[pause:0.5]` доступна для обычного текста. Приложение создаёт
между фрагментами цифровую тишину. Её длина добавляется к собственным паузам
модели; это не точная настройка расстояния между окончаниями произнесённых слов.
Вставка паузы и эмоции сохраняет выделенные слова.

Seed относится к генерации конкретной моделью. Он не сохраняет голос между
разными моделями и не гарантирует одинаковые байты при смене библиотек или
способа запуска. Для сохранения узнаваемого голоса используйте тот же профиль.

## Разметка зависит от модели

Fish:

```text
[whisper] I thought the recording was lost.
[laughing] Wait, it is safe. We can continue the lesson.
```

Chatterbox Turbo:

```text
[sigh] I thought the recording was lost.
[chuckle] Wait, it is safe. We can continue the lesson.
```

Orpheus:

```text
<sigh> I thought the recording was lost.
<laugh> Wait, it is safe. We can continue the lesson.
```

Dia:

```text
[S1] I thought the recording was lost.
[S2] Wait, it is safe. (laughs)
[S1] We can continue the lesson.
```

Эти четыре примера действительно запускались в двух окружениях. Это не гарантия
силы эмоций или различия тембров Dia; результаты и спорные слова перечислены
в [проверке качества](model-quality.md). Синтаксис сверялся с материалами авторов
[Chatterbox](https://huggingface.co/ResembleAI/chatterbox-turbo),
[Orpheus](https://github.com/canopyai/Orpheus-TTS#prompting) и
[Dia](https://huggingface.co/nari-labs/Dia-1.6B#features).

В Qwen CustomVoice/VoiceDesign, VoxCPM2 и IndexTTS используйте доступный список «Подача» вместо этих тегов.
Обычные модели могут отвергнуть чужие теги. Профиль всегда содержит точный текст
эталона, без эмоциональной разметки, которую человек не произносил.

Для Silero предусмотрен отдельный формат:

```xml
<speak>Пример текста. <break time="500ms"/> Продолжаем.</speak>
```

Кнопка паузы внутри такого документа вставляет `<break>` внутри `<speak>`,
сохраняя XML. Для Silero 02.11 проверен настоящий синтез после такой вставки
в интерфейсе, сохранение текста и выбор готового голоса.
[SSML автора](https://github.com/snakers4/silero-models/wiki/SSML).

## Остальные задачи

Для расшифровки эталона можно выбрать Whisper Base, Small, Medium, Turbo,
Large V3, Faster Whisper Large V3, GigaAM v3, Qwen3-ASR или Parakeet v3.
Список языка записи зависит от выбранного распознавателя. Расшифровка остаётся
редактируемой: перед сохранением проверьте каждое слово.

OpenVoice V2 меняет тембр загруженной записи на выбранный профиль. Текст сначала
нужно озвучить синтезатором или записать самостоятельно. MOSS SoundEffect создаёт
звук по описанию с выбранной длительностью 1-30 секунд. Эти инструменты открываются
из установленной карточки модели.

Resemble Enhance используется во вкладке «Улучшение аудио», а также для дубля
или итоговой записи. Удаление шума и восстановление звучания регулируются отдельно;
сильное восстановление может изменить речь. Сравнение «до/после» выравнивает
громкость только для прослушивания. Применение создаёт отдельную версию.
