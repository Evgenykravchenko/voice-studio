# Публикация исходников

Публикуйте только папку этого проекта в отдельном репозитории. Родительская
рабочая папка может содержать другие приложения и собственные настройки Git.
Не загружайте рабочую папку целиком через веб-интерфейс: он не применяет `.gitignore`.

В Git исключены локальные окружения и кэши, модели, профили, проекты SQLite,
исходные и готовые аудиофайлы, журналы, сборки, `.env` и файлы ключей.
`frontend/src/audio-data.json` — необязательная локальная metadata демозаписей;
в чистом checkout её нет. Личные файлы пользователя сохраняются на его устройстве.

Проверка 02.11.2026: файлы для публикации проверены на характерные секреты,
личные пути и имена, крупные файлы, аудио/веса/базы; проверено также содержимое
включённых архивов native-зависимостей. Это проверка состава публикации,
а не гарантия отсутствия любых уязвимостей или будущих секретов.
Перед следующим выпуском повторите проверку новых файлов и истории Git.

Собственный код — MIT; лицензии зависимостей и моделей перечислены отдельно.
Текущий поддерживаемый вариант — локальная установка на macOS/Apple Silicon.
Все 45 моделей выполнили контрольные задачи; известные ограничения качества
сохранены в [отчёте](release-status.md). Это не аттестация всех языков, компьютеров
или произвольных записей.
