# Roadmap

**English** · [Русский](roadmap.ru.md) · [Home](../README.md)

Voice Studio 0.1.1 runs locally on macOS 14+ with Apple Silicon.
This page describes direction, without promising dates. Check [release status](status.md)
for what is supported today.

## Available now

- Speech generation with reusable voice profiles, built-in speakers and voice descriptions where supported.
- A catalog of 45 downloadable models for synthesis, recognition and audio tools.
- Saved projects, takes, scene editing and final audio export.
- Audio enhancement with separate noise removal and restoration controls, plus before/after listening.
- English and Russian interfaces, with light, dark and system themes.

## Next areas

| Area | Intended outcome |
| --- | --- |
| First-launch feedback | Make setup failures and model choices easier to understand on more Apple Silicon Macs. |
| Model storage | Remove an installed model from the interface and show the disk space it uses. |
| Windows and Linux | Add platform-specific runtimes, setup and inference checks. These platforms are not supported yet. |
| Speech quality guidance | Improve model-specific examples for pronunciation, long scripts and expressive delivery. |
