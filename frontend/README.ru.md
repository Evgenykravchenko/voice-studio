# Voice Studio · интерфейс

[English](README.md) · **Русский** · [Документация пользователя](../README.ru.md)

React, TypeScript и Vite. Шесть разделов: озвучка, проекты, голоса, модели,
библиотека и улучшение аудио. Java API сохраняет проекты и профили, управляет
скачиванием и заданиями моделей. Обычно Java раздаёт готовую сборку на 4173;
при разработке Vite работает на 4173 с прокси API на 7080.

Для полного приложения используйте корневой скрипт запуска. Режим разработки
и проверки описаны в [руководстве](../docs/development.ru.md). Bootstrap
устанавливает локальные Node/pnpm; глобальные пакеты не нужны.

## Сборка и проверки

В `package.json` есть `typecheck`, `build`, `test:menu`, `test:sites`.
Сборка выполняет TypeScript, Vite и `scripts/prepare-sites-build.mjs`.
Создаются `dist/client/index.html`, worker статической поставки и её метаданные.
Этот worker раздаёт файлы и не заменяет Java/Python-сервер моделей.

Все frontend-проверки запускаются из корня:

```sh
./.runtime/toolchains/node/bin/node --test frontend/tests/*.test.mjs
```

Проверки упаковки ожидают готовую сборку. Перед пересборкой раздаваемого интерфейса
остановите приложение. Личные аудио из `public/audio/` в сборку не входят.
`src/audio-data.json` — необязательные локальные данные примеров, исключённые из Git.

## Правила интерфейса

Используйте общие Select, FileUpload, AudioPlayer и компоненты волн. Сохраняйте
RU/EN, темы, клавиатурное управление и адаптивность. Язык интерфейса не переводит
текст и не меняет язык речи. Для снимков и интеграционных проверок нужны отдельные
API/база и анонимные файлы.
